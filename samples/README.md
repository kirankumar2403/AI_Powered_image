These files demonstrate the seven visual conditions the system is trained to recognize.

- `01_acceptable_clean.png` — synthetic clean scene (ACCEPTABLE)
- `02_blurry.png` — Gaussian blur
- `03_underexposed.png` — darkened
- `04_overexposed.png` — clipped highlights
- `05_noisy.png` — Gaussian / salt-pepper noise
- `06_severely_degraded.png` — combined blur, noise, contrast crush
- `07_potential_visual_defect.png` — localized scratch, blob, or stain
- `08_corrupted_not_an_image.png` — invalid bytes (file corruption; rejected at validation)

Generated by `python scripts/generate_dataset.py` (except the corrupted file).
